# pin-images

Public host for Pinterest pin graphics, served via jsDelivr.

Used by the bulk-upload CSV pipeline in `_Pinterest-Bot`.
Pinterest's `Media URL` column requires a public direct link, which is
the only reason this repo is public. These are marketing graphics that
publish to Pinterest anyway.

URL pattern:
https://cdn.jsdelivr.net/gh/smayesyourtc-gif/pin-images@main/<folder>/<file>.png
